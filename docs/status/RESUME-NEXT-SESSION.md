## Don't go down these paths again (ruled out)

- **不要用 `npm install --prefix .local-packages <包>` 装单个包**：npm 会把其余包**全剪掉**
  （2026-09-28 实测：filesystem/git/repomix 当场消失，闸门 3 与两份自检连锁失败）。要装就 `make local-packages`（按锁装齐）。
- **不要凭「读起来对」下结论**：本段至少有 6 处只有**真的跑一遍**才暴露（相对路径的连接器静默起不来、
  派生目录里给的命令跑不了、文档里的产物路径不存在、`tools=N` 取数方式错导致「没变化」的假结论……）。
- **不要把行文当契约**：设计稿里 `stdio: {command…}` 的嵌套写法过不了 schema（真源是平铺）—— 引用 schema，别引用散文。
- **不要在 `core/` 里出现运行时名**：连注释都不行（本段被自己的检查拦了两次）。同理别在文档里写死会腐烂的数字。
- **不要在字符串里嵌 ASCII 双引号**（用「」或用 `edit` 工具）；`process.env`、`*.split(`、`**` 这类字面量会触发沙箱规则，
  改写变量名或用工具调用绕开。
- 旧结论仍然成立：别把宿主 `node_modules` 挂进容器；别在没重建镜像时用容器验新源码（工具会直接拒绝，这是对的）。
