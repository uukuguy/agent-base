# dsh-agent-base

企业智能体的**基座** —— 不是最终应用。

基座提供可复用的启动底座（基础配置、基础镜像、模板、脚手架、校验、文档）；
企业在它之上派生各自的智能体应用。

## 当前状态

**设计阶段，实现尚未开始。**

设计文档：[`docs/specs/2026-09-25-enterprise-agent-base-design.md`](docs/specs/2026-09-25-enterprise-agent-base-design.md)

设计文档 §6.2 尚有 3 个决策点待定，定稿后才进入实现。

## 基座与应用的边界

- 基座**不含任何业务智能体**
- 应用派生到基座**之外**，且不回头修改基座
- 详见设计文档 §1.2

## 设计文档的阅读方式

全文按三类标记组织，**因为它们的老化速度不同**：

| 标记 | 含义 | 老化速度 |
|---|---|---|
| 【dsh 专有】 | dsh 平台的机制与约束，均有实测证据 | 快 —— 随上游版本变化 |
| 【基座通用】 | 任何 agent 框架下企业基座都该有的东西 | 慢 —— 跨框架长期成立 |
| 【本项目决策】 | 在上述两者之上做的取舍 | 中 |
