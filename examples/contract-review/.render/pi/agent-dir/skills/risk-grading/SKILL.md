# 给条款分级

## 四个等级

| 等级 | 什么时候是这一级 |
|---|---|
| **高** | 直接造成我方义务无限扩大、责任无上限、或权利被单方剥夺 |
| **中** | 明显偏离对等，但可通过谈判修改；或触发条件模糊、容易被对方利用 |
| **低** | 表述不规范，但实质影响有限；主要是清晰度问题 |
| **缺漏** | **合同没写**，而按常规应当写（例如没有争议解决条款、没有终止条件） |

**「缺漏」不是风险等级的另一档，它是另一类东西** —— 缺漏意味着"这份合同没解决这个问题"，
处置是**要求补上**；而风险意味着"写了，但对我方不利"，处置是**要求修改**。
把两者混在一列里，读者就没法判断该找谁做什么。

## 分级必须带依据

每一级后面写一句「为什么是这一级」，并且依据要**指向条文本身**（引用原文里的关键词或结构），
而不是"一般来说这种条款风险较高"。

> 反例（不合格）：「3.2 商业风险较高」—— 这等于没写依据。
> 正例：「3.2 高 —— 原文未限定答复内容与形式，我方可能被迫接受对方单方主张」

## 不确定时

依赖外部事实才能判断的（当地法律、行业惯例、对方真实意图），
**不要硬给等级**：标为「需人工判断」，并在依据里写清**缺什么信息**。
