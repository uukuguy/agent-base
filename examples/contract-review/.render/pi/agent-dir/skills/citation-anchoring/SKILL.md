# 回指原文自检

## 为什么必须有这一步

审阅表最常见的失效不是"分错级"，而是**结论回不到原文**：读者拿着表去核对，发现原文里没有那句话。
这张表就废了 —— 它看起来有依据，实际无从核查。

## 怎么做

1. 对表里每一行，检查「原文摘录」能否在合同文本里**逐字找到**（标点差异可接受，用词差异不接受）。
2. 找不到的行，分两种处置：
   - 是**概括**写的 → 换成原文原句
   - 是**推断**出来的 → 从表里删掉，或改写成「合同未规定该情形」（那是`缺漏`，不是引用）
3. 跑一遍机械自检（下面的脚本），把结果贴出来。

## 机械自检脚本

```bash
node scripts/check-anchors.mjs <审阅表.md> <合同.txt>
```

它做的事很笨但有用：逐行取「原文摘录」列，去合同文本里找；找不到就报出行号。
**用途是让自己知道哪几行是硬伤**，不是让机器替你负责。

（脚本在 `scripts/check-anchors.mjs`，是纯 Node 实现，无依赖。）
